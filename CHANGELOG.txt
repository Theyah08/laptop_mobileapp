PROSFORA GIFT SHOP - CHANGE LOG
Updated: 2026-10-30

Purpose
-------
This is a documentation-only summary of application changes made during the
work in this project. It does not participate in Flutter builds or runtime
behavior. The project workspace did not provide Git history, so this records
the changes known from the implementation work rather than claiming to be an
automatically generated source diff.

Application and authentication
------------------------------
- Preserved Firebase initialization, Firebase email/password authentication,
  and the existing authentication-state routing.
- Added show/hide password control to the login password field.
- Prevented repeated sign-in submissions while sign-in is in progress.
- Removed the extra HomePage navigation push after successful sign-in; the
  existing Firebase auth-state router handles the transition.
- Corrected the HomePage import filename casing for platform compatibility.

Product catalog and local data
------------------------------
- Kept the GitHub Gist as the initial, read-only product source.
- Added local catalog persistence with shared_preferences. The Gist is loaded
  only when no saved local catalog exists.
- Added product identifiers and JSON serialization for saved product records.
- Implemented local add, edit, and delete product operations with form
  validation, delete confirmation, and catalog refresh after changes.
- Normalized the existing catalog categories and updated category filters and
  product editing controls to use consistent gift-shop category names.
- Added stable identifiers for seeded products so local favorites can be
  matched after reloading the source catalog.

Product photos
--------------
- Registered the existing assets/Product folder with Flutter.
- Mapped the current Gist product names to the bundled photos and displayed
  photos in product cards, catalog rows, wishlist rows, product details, and
  cart-era thumbnails where applicable.
- Added photo selection and preview to the product editor only; normal browsing
  does not expose a permanent upload field.
- Added durable native photo storage by reading the selected image bytes and
  writing them into the app's documents directory, instead of relying on the
  picker's temporary file path.
- Added browser-safe image persistence using base64 data URLs and memory image
  rendering, avoiding unsupported dart:io calls on Flutter Web.
- Added the iOS photo-library usage description for image_picker.

Wishlist, account, settings, and orders
--------------------------------------
- Added a persistent Wishlist scoped locally by the signed-in Firebase user ID.
- Added heart controls, duplicate prevention, immediate updates, product
  details access, and an empty Wishlist state.
- Added Profile details for Firebase display name/email, locally saved phone,
  local profile photo selection, profile editing, and sign out.
- Added working Settings actions for profile navigation, privacy information,
  notification limitations, sign out, and confirmed clearing of the cached
  catalog.
- Added Orders navigation and an honest empty state. Order placement, payment,
  and a persistent order backend are not configured, so no purchases are
  fabricated or recorded.

Cart
----
- Removed Add to Cart controls and cart/checkout behavior from the product
  browsing experience. No cart feature was restored during later refactoring.

Source organization
-------------------
- Flattened lib so it has no nested folders; updated source imports.
- Merged product editing and shared product-image rendering into
  lib/product.dart.
- Merged Profile and Settings into lib/profile.dart, and Wishlist and Orders
  into lib/orders.dart.
- Merged the dashboard into lib/home_page.dart.
- Kept the application entry point, Firebase configuration, catalog API,
  login, and item catalog as root-level Dart files in lib.

Dependencies and platform setup
-------------------------------
- Added shared_preferences for local persistence.
- Added image_picker for gallery selection.
- Added path_provider and path for native persistent image paths on supported
  non-Android platforms.
- Added Android INTERNET permission for the initial Gist request.
- Added iOS photo-library usage text for gallery access.

Validation recorded
-------------------
- Flutter widget/data tests passed, including password visibility, category
  normalization, product image mapping, stable seeded product IDs, and
  product image-path persistence across catalog save and reload.
- Focused Flutter analysis passed for the refactored feature files.
- Android debug APK builds succeeded after the local image storage and source
  organization changes.
- Flutter Web build succeeded after browser-specific image handling was added.
- Full-project analysis has reported two existing withOpacity deprecation
  notices in the login screen; these are informational and unrelated to the
  change log itself.
